# Student OS

> A personal AI agent for a student's learning and career journey.

## Vision

Students have access to thousands of creators, courses, videos,
communities, projects, and career resources.

The problem is not a lack of information.

The problem is knowing:

- What should I learn?
- Which resources are relevant to me?
- Which advice should I follow?
- What am I missing?
- What should I build next?
- Am I ready for a job?

Student OS uses a personal AI agent to understand the student's
goals, skills, experience, interests, creators, resources, and
progress.

It identifies learning gaps, builds an adaptive roadmap,
recommends relevant resources, tracks progress, and connects
learning with career opportunities.

## Core Flow

Student
→ Profile
→ Creator & Resource Context
→ AI Gap Analysis
→ Personalized Roadmap
→ Recommended Resources
→ Next Action
→ Progress
→ Job Readiness
→ Career
